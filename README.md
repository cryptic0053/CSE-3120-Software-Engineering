## Repository layout

Work is organised per lab session or assignment. Each directory holds the source for
that task, together with any input data and generated output it needs.

## Running the code

Requirements vary per task; each directory is self-contained. In general:

```bash
git clone https://github.com/cryptic0053/CSE-3120-Software-Engineering.git
cd CSE-3120-Software-Engineering
```

Then open the directory for the lab you are interested in and follow the tooling
appropriate to Java.
